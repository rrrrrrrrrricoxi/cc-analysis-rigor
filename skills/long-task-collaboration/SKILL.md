# 长任务里的人机协作

## 总纲：顺序错了，再好的内容也接不住

长任务最常见的失败不是做错，是**顺序错**：在对方还没和你建立起共识之前，就请他做需要共识才能做的判断。

> 真实案例：agent 读完全部材料后，一次问了三个问题。第一个问「这份报告的定位是对内完整版 / 管理层简报 / 对外版」—— 当场被回答。第二、第三个问「要不要包含那几条前瞻建议和待确认假设」「动笔前要不要先跑复现脚本核对主效应」—— **两问全部空白并被驳回**。对方随后写道：
>
> 「我现在需要你跟我一起过的就是这几份报告，以及这几份报告里面内容的 legitimacy，而不是现在你让我通过这几份报告来判断后面要做什么。……**所以我现在对于你的建议和三个待确认的假设的 context 为 0**。」

差别在于：第一个问题的选项是「给谁看」，凭身份和职责就能判；后两个问题的选项**全是 agent 自己刚读出来的产物和数字** —— 对方对它们的 context 是零。

**先带他过一遍，建立共识、核验合法性，再谈前瞻决定。**

## 什么该问人，什么该自己定

### 该问：凭身份就能回答的

受众是谁、口径松紧、风险偏好、优先级、术语选择、要不要做某件有成本的事。这些依赖的是**对方的位置和判断**，不是对材料的了解。

### 不该问：需要你的 context 才能答的

选项里只要引用了**对方还没被你带着过一遍**的中间产物、内部概念或具体数字，就不能问。这类提问不是在收集信息，是**把理解负担转嫁出去** —— 结果是空转一轮外加对方明确不满。

要问，先讲清楚，下一轮再问。

### 也不该自己定：成本判断

**识别出一条可行但你判断"太贵/超范围"的路径时，必须作为决策抛给对方，不要自己写进"未来工作"判它出局。**

成本判断依赖领域知识，而你不掌握。**你眼里的"明年再说"，可能是对方眼里的一小时活。**

> 真实案例：两轮并行检索拿不到需要的指标，agent 汇报「做不出来」，并把正确的做法写成了「**这是明年该做的准备工作之一**」。对方一句话把它拉回当期：那个量是**算出来的**，只要拿到更底层的逐日数据自己算就行。换了做法后，全部点位一次拿到。

**把它埋在段落末尾等于没说。** 要作为一个明确的岔口摆出来。

## 怎么把选择呈现出来

### 主观的选择要做出来给人看，不要用文字描述

关于「长什么样 / 读起来怎么样」的选择 —— 版式、配色、语气、结构 —— **真的做出 2–3 个可打开的版本**。

**人对审美与措辞的偏好说不清楚，但一眼认得出。** 文字选项只能表达你已经想到的那个框架；做出来的版本会暴露你没想到的维度。

> 真实案例：agent 跳过了流程里写明的"生成几版样张让人挑"这一步，直接套用了已有产物的风格。对方的反馈是：「这一页上面，Too much information。另外，这一个 skill 不应该能采访我看我喜欢什么样的前端板式吗？」补做三版样张之后，对方一次选定，**此后再没回头改过风格**。

**流程里写明的"让人挑"检查点，不许因为"我从已有材料能推断出他的偏好"而跳过。** 跳过省下的十分钟，代价是整页重做。

### 选项被全否 = 轴错了，不是选项错了

三个选项一起被否，说明**你取值的那根轴选错了**。它们是从你已经承诺的那个框架里长出来的，所以会一起错、也会一起看起来合理。

不要马上换一批同轴的新选项。**先问「你不满意的是哪一维」，拿到新轴再出选项。**

## 怎么接收反馈

### 动手前先逐条复述

用自己的话把这一轮反馈逐条复述一遍，**每条翻译成一个具体动作**，再开工。

**为什么**：人的反馈常常是三句短话夹一张截图，其中往往有一条是「**你违反了流程**」而不是「这里有个 bug」。不复述就会只挑最像 bug 的那条做，剩下的静默丢弃 —— 而丢掉的那条常常是最贵的。

> 真实案例：一次三条混合反馈（信息过载 / 你没走选型流程 / 这页的核心是哪张图）。agent 开头写：「这三条反馈都收到，而且都对。**让我先复述确认，免得又走偏**」，逐条译成动作，其中第二条译成「我没走 skill 的选型环节 —— 这是我的失误」。这一轮之后该页没有再返工。对照组：另一次四点反馈没有复述，其中一点被做成了字面最小修，随后返工。

### 提一处 = 提一类

对方是浏览时随机撞见一处才提的，**他默认你会推广到同类**。只修字面那一处会被读成敷衍，而且同类问题会在后面几轮反复消耗来回。

**抽样 → 扫同类 → 再改。**

> 真实案例：对方指出侧边栏字号太小，agent 只改了侧栏。下一轮：「**你还真只提侧边栏的字号啊，文档上还有其他好多小字，你都不管吗，让谁看？？**」agent 的复盘：「我在挨页打补丁，应该一次扫全。」

### 「不一致」没有告诉你哪个是对的

对方说两处不一致时，**不要默认统一到"更早存在的"或"更像系统默认的"那一套**。人往往是**喜欢新的那一套才没提它**。

向他**曾经点名认可过**的那套靠；拿不准就直接问一句哪个是基准。收敛错方向是一次回归，要多花两轮修回来 —— 而且它同时删掉了一个已被认可的决定。

### 随口问的事实性问题，是对你假设的证伪测试

对方问一个看似简单的事实性问题时，**他脑子里有一个你没有的因果模型正在报警**。这类问题命中率极高。

**查完先自查：这个答案会不会推翻我已经写进产物里的某个论断？** 会的话主动说出来，并提出改法。

> 真实案例：对方问「那几条不增不减的样本，在分组变量上怎么分布？」查完 agent 的结论是：「**这一问推翻了我原来的对照逻辑**」—— 那几条落在本来就贴零的那一档，拿它们当对照是无效的。agent 随即把结论重写成「能说 / 不能说 / 完全不知道」三段，对方回「加进去」。

## 怎么汇报

### 子 agent 的结果不许原样转发

原样转发 = **把分诊工作推给对方**。得到的回复会是「太 dense 了」。

重新综合成：**按严重度分层 + 编号 + 每条带位置和可执行的改法**，末尾**明确交还调度权**（做哪几条、什么顺序，你说）。另外单列「你明确说过不要动的」，避免误改。

**为什么有效**：分层编号把对方的注意力精确投到需要他判断的地方。他对高等级逐条表态、对低等级一句话批发，一个来回就能把几十条变成明确工单。

> 真实案例：只读评审回来 16 条，重排成「阻塞 2 条 / 明显 7 条 / 打磨 7 条」，结尾写「按你说的，我没动手。要动哪几条、什么顺序，你说。」对方的整条回复：
>
> 「1、2、3 做 / 4 没看懂。/ 5、6、7 按你的推荐来，注意文字如果溢出两行，第二行不要只排版一两个字 / 8、9 做。**打磨的都做**」

### 每次汇报固定挂一段「还欠着的」

**为什么**：人把汇报里的「接下来我要做 X」当**承诺**记账。而小修复天然会插队 —— 它们便宜、显眼、刚被提到。大件于是一轮轮滑走，直到对方点名追债；那时损失的不只是时间，还有「你到底在不在干正事」的信任。

**要延后就明说，并重新排期。** 不允许被新进来的小修复无声地顶掉。

> 真实案例：agent 连续两轮以「接下来动结构重排」收尾，却两轮都去修了新提的小问题。第三轮对方开口就是：「**我们说的要把……整合到主汇报里面去，怎么都没做？**」此后 agent 把「还欠着」做成每份汇报的固定收尾段，对方开始直接从这段清单调度 —— 某一轮的全部指令就是六个字：「**先继续做欠着的**」。

## 「找」和「改」要分成两步

**评审/调研阶段明确声明只读、不动文件；汇报之后等对方点单再动手。**

**为什么**：
- 边看边改会让对方失去「存在过哪些问题、哪些值得修、哪些是你自作主张改的」这个全局视野。
- 声明只读同时是**给对方的一个安全承诺**：他可以放心让长任务跑，不必担心醒来时产物已经被改成另一个样子。

配套两条：
- **评审进行期间不碰被评审的文件** —— 否则评审者看的和你改的不是同一份。
- **主动提一件不冲突的事填满这段时间**，别让对方觉得在干等。

> 真实案例的汇报模板：「回来我把清单原样报给你，你定哪些动、哪些不动，我再动手。**期间我先不碰主报告，避免和它看的是同一份不一致的文件。要我趁这段时间把另一份文件的字号做同样的全局抬升吗？那是另一个文件，不冲突。**」

派子 agent 时把验收标准写进 prompt：要求按严重度排序、每条要有**具体位置 + 客观问题 + 可执行改法**，**明确禁止「优化一下」这类空话**，并让它顺带指出哪些地方做得好、别让人误改。

---

## 不值得并行的活，明说不并行

编排有开销。机械的文本替换、一致性扫描这类活，自己做完并验证，比派一支舰队快。

在汇报里把这个裁量说出来（「这是一批机械改动，不值得起子 agent，我直接做了并验证」），对方就知道你在按成本决策，而不是偷懒或炫技。

## 红旗表

| 想法 | 现实 |
|---|---|
| 「材料我读完了，把接下来的几个岔口列出来让他拍板最高效」 | 他还没读过你读的东西。对他 context 为 0 的产物提问，只会拿到空白。先带他过一遍。 |
| 「他只提了这一处，那就改这一处，多改是越界」 | 他是随机撞见一处才提的，默认你会推广到同类。抽样→扫类→再改。 |
| 「他说这两处不一致，统一到原来那套就行」 | 「不一致」没说哪个是对的。他没提的那套往往正是他喜欢的。 |
| 「先把刚提的小修做完，那个大改下轮再动」 | 小修会无限插队。要么先做完欠的，要么明说延后并重新排期。 |
| 「这个视觉方向我能推断出他的偏好，先做一版更快」 | 人对审美说不清但一眼认得出。流程里的"让人挑"是最便宜的一次对齐。 |
| 「三个选项他全否了，再想三个更好的」 | 全否说明轴错了。同轴换词只会一起再错。先问是哪一维不满意。 |
| 「子 agent 的结果很详细，原样转发最忠实」 | 原样转发＝把分诊推给他，回复会是「太 dense 了」。分层+编号+交还调度权。 |
| 「审阅期间顺手把明显的问题改掉，省一轮」 | 他会失去全局视野，评审者和你还可能改到同一份文件上打架。 |
| 「他问了个小问题，查一下告诉他就行」 | 他问是因为有个你没有的因果模型在报警。答完自查：这会不会推翻我已交付的论断？ |
| 「这条路可行但太贵，写进『未来工作』提一句」 | 成本判断依赖领域知识，你不掌握。作为决策抛出来。 |
| 「这批数据网上应该有，派一队 agent 去搜」 | 「上网找 X」里藏着岔口：找现成口径 vs 抓原始数据自己算。先对一句来源形态。 |
| 「把发现写成明确的行动建议，对决策者更有用」 | 证据撑不住的行动建议是越界。写成「一处异常·待查」，不是「别这么做」。 |
